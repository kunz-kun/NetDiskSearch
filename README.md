# 网盘聚合搜索下载器

Windows 桌面工具，用公开搜索引擎聚合百度网盘、迅雷云盘、阿里云盘、夸克网盘、123云盘、天翼云盘和蓝奏云的公开分享页。

## 功能

- 按关键词搜索公开可索引的网盘分享链接
- 按网盘平台筛选、去重结果
- 浏览器打开、复制分享链接
- 内置 HTTP/HTTPS 公开直链下载器
- 下载进度、速度、取消和 `.part` 断点续传
- 对登录、提取码和平台权限保持原有限制，不尝试绕过

## 使用

运行 `dist\NetDiskSearch.exe`。输入关键词并选择平台后搜索。普通网盘分享页会在官方网页中打开；如果拥有合法的公开文件直链，可粘贴到下方地址框并使用“内置下载”。

搜索结果依赖公开搜索引擎的网络可用性与收录情况，并不保证每条分享仍然有效。

## 从源码构建

在 PowerShell 中运行：

```powershell
.\build.ps1
```

程序只使用 Python 标准库；构建需要 PyInstaller。

## 使用边界

本工具只检索搜索引擎已公开收录的页面并下载用户提供的公开直链，不破解提取码、不绕过登录或会员限制。请只搜索和下载你有权访问的内容。未签名的个人构建版在部分 Windows 电脑上可能触发 SmartScreen 提示。
